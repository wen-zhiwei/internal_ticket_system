# Feature 10：双岛客服工作台

## 目标

- 左侧导航删除重复的“新建工单”入口。
- 工单首页调整为双岛布局：左侧客服助手，右侧工单中心。
- 左侧复用现有助手的真实对话、查单、草稿整理和确认创建能力，不复制业务逻辑。
- 工单中心内部继续保留“新建工单”按钮和完整筛选、统计、列表能力。

## 实现

- `AssistantConversation`：可复用的助手对话主体。
- `AssistantWidget`：其他页面继续使用右下角浮窗，并复用同一对话主体。
- `App`：工单首页组合左侧助手与右侧 `TicketQueue`；新建和详情页保留浮窗助手。
- 双岛布局在窄屏自动改为上下排列，目录栏仍支持展开和收缩。
